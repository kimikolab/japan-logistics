# ニッポン物流網（プロトタイプ）

日本の47都道府県を路線で結び、荷物を自動配送する物流ネットワーク構築ゲームのプロトタイプ。
路線と車両の配置を工夫して「遅延しない物流網」を作ることが遊びの中心で、遊ぶうちに都道府県の位置関係に馴染むことを狙っている。

`proto/index.html` をブラウザで開くと、そのまま遊べる。

## 現在のゲーム仕様

数値はすべて仮設定で、調整前提。値の定義は `proto/core.js` の冒頭にある。

### 目的と進行

| 項目 | 内容 |
|---|---|
| 開始時 | 関東地方のみ解放。神奈川→東京→埼玉→群馬（小型2台）、千葉→東京（小型1台）の2路線が開通済み。茨城・栃木は未接続 |
| 地方の解放 | 8地方（北海道、東北、関東、中部、近畿、中国、四国、九州・沖縄）。解放済みの地方に隣接する地方へ進出できる |
| 進出の条件 | 資金10,000G、かつ直近3日の納期遵守率が90%以上 |
| 完成条件 | 47都道府県をすべて接続し、納期遵守率95%以上の週を4週連続で達成 |
| 完成後 | 遵守率95%以上の週について、最高利益と最少車両数を記録する |
| 敗北 | なし。資金がマイナスになっても続行できる（購入と進出ができなくなる） |

### 地図と時間

| 項目 | 内容 |
|---|---|
| 都市 | 47都道府県に1都市ずつ（原則として県庁所在地）。実際の位置に配置 |
| 道路網 | 75区間の簡略グラフ。路線は道路網に沿ってのみ引ける |
| 道路時間 | 直線距離×1.3÷時速75kmを0.25時間単位に丸めた概算 |
| 個別指定の区間 | 北海道—青森 8時間（航路）、広島—愛媛 2.75時間、鹿児島—沖縄 24時間（航路） |
| 時間の進み | 等倍で1ゲーム時間＝約1.67秒（1日＝約40秒）。停止・1倍・3倍・10倍を切り替えられる |

### 路線と車両

| 項目 | 内容 |
|---|---|
| 路線 | 2〜6都市を順に指定。車両は両端で折り返して自動往復する |
| 通過 | 隣接していない都市を続けて指定すると、間の都市は停車せず通過する |
| 停車 | 停車・荷役に1都市あたり0.5時間 |
| 編集 | 停車都市を外す、先頭または末尾に追加する。確定すると車両は始発に戻り、積み荷はその場の都市に降ろす。費用なし |
| 小型トラック | 積載10箱、購入4,000G、維持費 週2,000G、売却2,000G |
| 大型トラック | 積載20箱、購入9,000G、維持費 週3,500G、売却4,500G |
| 車庫 | 路線から外した車両は車庫に入る。維持費なし。他の路線の増車や新路線に無料で使える |
| 路線の廃止 | 車両は車庫へ、積み荷はその場の都市に降ろす |

### 荷物

| 項目 | 内容 |
|---|---|
| 発生 | 路線で到達できる都市の組にだけ発生する。未接続の都市には発生しない |
| 需要量 | 都市の重み（人口規模を参考にした仮値）の積÷（1＋道路時間）に比例。1件1箱、ランダムに発生 |
| 納期 | 発生から「8時間＋道路上の最短時間×4」 |
| 納期超過 | 超過後6時間は配送を続ける。それを過ぎるとキャンセルされ、納期切れとして数える |
| 経路 | 路線を変えるたびに経路表を再計算する。乗り継ぎ待ちは運行間隔の半分で見積もり、乗り継ぎ1回につき1時間のペナルティを加える |
| 積み込み | 進行方向が合う荷物を、納期が近い順に積む。納期を過ぎた荷物は後回し |
| 特産品 | 出荷元の県ごとに1品目を表示する（表示のみ。仮置き） |

### 資金

| 項目 | 内容 |
|---|---|
| 初期資金 | 20,000G |
| 配送収入 | 1箱あたり「10G＋道路時間×4G」。納期を過ぎて届いた場合は半額、キャンセルは0 |
| 車両維持費 | 路線に配置した車両にだけかかる |
| 開通祝い金 | 新しい都道府県をつなぐと1県につき1,000G |
| 初出荷祝い金 | 各県の特産品が納期どおりに初めて届くと1,000G |
| 路線別の収支 | 配送収入を乗車時間の比で各路線に配分し、週ごとに維持費と比べる |

### 状態の表示

| 項目 | 内容 |
|---|---|
| 納期遵守率 | 直近72時間に結果が出た荷物のうち、納期内に届いた割合 |
| 都市の状態 | 遅延：納期切れの荷物が待っている、または直近24時間のキャンセルが2件以上。混雑：待ち荷物が15箱以上。それ以外は順調 |
| 健康診断 | 問題のある都市の一覧と、先週の収入・維持費。維持費が収入の85%を超えると警告 |
| 都市の詳細 | 状態の説明、行き先別の待ち荷物、通る路線の運行間隔と次の便までの時間 |
| ヒント | 「次の一手」と対処の助言。既定では非表示 |
| 変更の結果 | 開通・編集・増減便・廃止の24時間後に、沿線の待ち荷物と納期切れを変更前と比較 |
| 週次レポート | 配達数、遵守率、収入、維持費、祝い金、利益を前週比つきで表示 |
| 積載率 | 出発時の積載量÷積載容量の移動平均。全体と路線別 |

### 地域の発展（試作・演出のみ）

物流が安定すると、地域が段階的に発展する。プレイヤーが直接操作する対象ではなく、配送の結果として変わる。
現時点では見た目とコメントだけで、需要や収入には影響しない。

| 項目 | 内容 |
|---|---|
| 発展段階 | 未接続 → 物流開通 → 物流定着（★） → 地域産業発展（★★） |
| 判定 | 週ごとに県別の実績を集計する。その県が発着地の荷物が5箱以上あり、納期遵守率が90%以上なら「安定した週」として数える |
| 段階の条件 | 安定した週が2週で物流定着、6週で地域産業発展。後退はしない |
| 表示 | 地図の都市の下に星、画面上部に「発展した県 n/47」、都市の詳細に段階と進み具合 |
| 地域の声 | 開通、初出荷、定着、発展、混雑、遅延、解消のときに、その県の特産品を織り込んだひとことが出る。同じ県からは48時間に1回まで |

### 地図の操作と表示設定

- ドラッグで移動、ホイールまたはボタンで拡大縮小。「営業圏」「全国」で表示範囲を合わせる。
- 路線カードや地図上の路線にカーソルを合わせると、その路線だけを強調する。押すと固定。
- 表示：通常／混雑（路線を薄くし、問題のある都市を強調）。
- 名前：県名／都市名。
- 問題の都市：自分で探す／地図に表示。「自分で探す」では、一覧から選んだ都市を地図上で見つけて押す。

### 保存

進行状況は約10秒ごとに、ブラウザの localStorage へ自動保存する。開き直すと続きから再開する。
「最初からやり直す」を2回押すと消える。別のブラウザや端末には引き継がれない。

### まだ入っていないもの

契約カード、信用度による制限、拠点の仕分け能力、季節やイベントによる需要変動、県内の複数都市、幹線と地域内の2層管理、効果音。

今後の候補と優先順位は [docs/backlog.md](docs/backlog.md) にまとめている。

## 構成

| パス | 内容 |
|---|---|
| `proto/core.js` | シミュレーション本体。画面に依存しない（Nodeで実行可能） |
| `proto/template.html` | 画面（地図描画・操作盤）。`/*CORE*/` `/*CITIES*/` `/*GEO*/` を埋め込んで使う |
| `proto/build.py` | `core.js` とデータを `template.html` に埋め込み、単体の `index.html` を作る |
| `proto/test.js` | 本体の動作確認（`node proto/test.js`） |
| `data/cities.json` | 47都道府県の代表都市（座標・地方・需要の重み・特産品） |
| `data/geo.json` | 簡略化した県境（描画用） |
| `data/build.mjs` | 県境データの生成スクリプト（`jpn-atlas` が必要） |
| `sim/` | 企画検証に使ったPythonシミュレーター（検証A・B・C） |

## ビルド

```
python3 proto/build.py   # proto/index.html を生成
```

`proto/core.js` か `proto/template.html` を変更したら、ビルドして `index.html` も一緒にコミットする。
外部への通信は Google Fonts のみ。

## 注意

- 道路時間と需要の重みは概算で、実データとの照合はしていない。
- 県境データの出典：国土地理院「地球地図日本」（npm パッケージ `jpn-atlas`、BSD-3-Clause 経由）。
